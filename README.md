# Kanalizaciya.uz

Сайт аварийной службы прочистки канализации в Ташкенте.

Одна статическая страница без сборки и без внешних зависимостей: `index.html`
со встроенными стилями и скриптом, шрифты и иллюстрации лежат рядом.
Никаких запросов на сторонние домены — сайт полностью работает, даже если
Google Fonts или любой CDN недоступны.

## Запуск локально

```
python3 -m http.server 4321
```

## Структура

| Файл | Что это |
|---|---|
| `index.html` | вся страница: разметка, стили, скрипт карты, микроразметка |
| `404.html` | страница ошибки в той же стилистике |
| `fonts/` | PT Serif, Golos Text, IBM Plex Mono — локальные woff2, латиница урезана до используемых символов |
| `img/*.webp` | иллюстрации в двух размерах (800 и 1400 px) для `srcset` |
| `img/og.jpg` | картинка для соцсетей, 1200×630 |
| `robots.txt`, `sitemap.xml` | для поисковиков |
| `CNAME` | привязка домена в GitHub Pages |

## Вес

Первый экран — около 215 КБ: сжатый html 19 КБ, кириллические шрифты 79 КБ,
иллюстрация 116 КБ. Остальные картинки грузятся лениво.

## Что на странице

Первый экран с телефоном и кнопкой звонка, блок «пробить ≠ прочистить»,
оборудование, мастера, порядок вызова, цены, интерактивная карта дежурства
по 12 районам Ташкента (границы — данные OpenStreetMap, ODbL), объекты,
отзывы, вопросы, финальный призыв.

Единственное целевое действие — звонок. Мессенджеров и форм на странице нет
намеренно: человек с засором звонит, а не переписывается.

## Требует замены на реальные данные

Перед переключением домена на этот сайт нужно заменить:

- **год основания** — сейчас везде указан 2014
- **цены** — сейчас ориентировочные, выдуманные
- **отзывы** — три отзыва в блоке «Что говорят клиенты» вымышленные,
  публиковать их на живом сайте нельзя
- **время подачи бригады по районам** — цифры в карте дежурства условные

## Правки

Все стили и скрипт внутри `index.html`. Цвета вынесены в CSS-переменные
в блоке `:root` в начале файла: поменяв там значения, можно перекрасить
весь сайт целиком.
