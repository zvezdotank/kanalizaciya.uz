# Kanalizatsiya24.uz

Сайт аварийной службы прочистки канализации в Ташкенте.

Одна статическая страница без сборки: `index.html` со встроенными стилями
и скриптом, плюс иллюстрации в `img/`. Шрифты подключаются с Google Fonts.

## Локально

Открыть `index.html` в браузере или поднять любой статический сервер:

```
python3 -m http.server 4321
```

## Что в файле

- Первый экран: телефон как главный элемент, кнопка звонка, иллюстрация выезда
- «Пробить и прочистить» — основное отличие услуги, с разрезом трубы
- Оборудование: промывочная установка и перечень остальной техники
- Мастера, порядок вызова, цены, объекты, отзывы, вопросы
- Карта дежурства: 12 районов Ташкента, границы построены по данным
  OpenStreetMap (ODbL), выбор района меняет время подачи и состав машины

## Требует замены на реальные данные

- год основания (сейчас указан 2014)
- цены
- отзывы
- время подачи бригады по районам
